# Imran Blog - International Travel Website

Welcome to the **Imran Blog** complete web source package.

## Features Included:
1. **Admin Panel Security:** Protected by password `Imran123@`. Admin can add new posts directly from the dashboard.
2. **Visitor Interface:** Clean, modern responsive blog layout with Like button, Star Ratings, and Live Comment section.
3. **5-6 Ad Slots Included:** 
   - Top Header Ad Banner (728x90)
   - Sidebar Rectangle Ad (300x250)
   - Sidebar Half-Page Ad (300x600)
   - In-Article Native Banner (Mid post)
   - Pre-Footer Banner (728x90)
   - Small Footer Ad
4. **Footer Sponsorship Link:** Includes Bengali text button `📢 বিজ্ঞাপনের জন্য যোগাযোগ করুন (ফেসবুক পেজ)` with customizable link attribute (`https://facebook.com/your-page-link-here`).
5. **Full Real Articles (English):**
   - 10 Best Places to Visit in Bangladesh
   - A Complete Travel Guide to the Sundarbans
   - How to Travel on a Budget in Bangladesh
   - Best Places to Visit in Bali for First-Time Travelers
   - How to Plan Your First International Trip
6. **Core Pages Included:**
   - Destinations, Travel Guides, Budget Travel, Food & Culture, Travel Tips
   - About Us, Contact Us, Privacy Policy

## How to use:
Simply extract `Imran_Blog_Website.zip` and open `index.html` in any web browser, or upload the files to any web hosting platform (e.g. GitHub Pages, Netlify, Vercel, or cPanel hosting).
